# Changelog

## 1.2.0

Initial public release for Sanctuary: Shattered Sun Playtest 0.0.1.21.1 and
Remmy's Mod Manager 0.17.0.

- Compact lobby layout with Vanilla and Overhauled modes.
- Built-in lobby presets, host slot and team controls, and bulk AI controls.
- Separate commander selection where supported and independent player colors in Overhauled mode.
- Category and individual-unit restrictions.
- Matching-build check before starting an Overhauled match.
- Windows batch installer with confirmation before overwriting an existing copy.
